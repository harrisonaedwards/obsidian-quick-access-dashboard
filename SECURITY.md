# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not open a public issue for an unpatched vulnerability.

Use synthetic paths and note names in reports rather than real vault data. Include the Obsidian version, plugin version, operating system, reproduction steps, and the security impact.

## Data boundary

Quick Access Dashboard does not use the network or read note contents. It stores Quick Access items in normal plugin data and aggregate access statistics in Obsidian's vault-specific local storage.
